# Loper Family Tree Builder

Installer-first fresh rebuild of the Loper Family Tree Builder.

## End-user installation goal

The finished Windows application is delivered as a single file:

`LoperFamilyTreeBuilderSetup.exe`

The end user does not need Visual Studio, PowerShell, Command Prompt, manual .NET commands, or manual SQL Server setup.

## Project rules

- .NET 10
- Permanent left-side navigation
- Dashboard-first work center
- Designed for approximately 1,600 people initially and significant future growth
- Robert J. Loper Legacy Numbers are immutable historical text
- Stable internal IDs are separate from Legacy Numbers
- No automatic duplicate merges
- AI remains proposal-first
- Original archive data and original media are preserved
- High-risk changes require backup, audit, review, and verification controls
